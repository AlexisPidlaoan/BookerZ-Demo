# BookerZ 🎟️

An event booking web app built with React (Expo Snack).

## Features

- 🔍 **Explore Events** — Browse and search events by category
- 🎟️ **Event Details** — View event info and book tickets
- 👤 **Profile** — View your profile, about me, and interests
- 🗂️ **Sidebar** — Navigate between pages with a slide-out menu
- 🔔 Notifications, Tickets, Calendar, Wishlist pages

## Files

| File | Description |
|------|-------------|
| `App.js` | Entry point |
| `Dashboard.js` | Main explore page with search and event cards |
| `Event.js` | EventCard and EventDetails components |
| `profile.js` | User profile page |
| `Sidebar.js` | Slide-out navigation menu |
| `BottomNav.js` | Bottom navigation bar |
| `Tickets.js` | Your booked tickets |
| `Notifications.js` | Notifications page |
| `EventCalendar.js` | Calendar view |
| `Login.js` | Login screen |
| `styles.css` | Shared styles |

## How to Run

1. Open [Expo Snack](https://snack.expo.dev)
2. Import or paste the files
3. Run on Web platform

## Built With

- React
- Expo Snack
- CSS (inline + styles.css)
